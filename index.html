🏠 About the Project

This dashboard is a fully interactive browser prototype. Voice recognition, device controls, simulated sensors, automation insights, emergency shutdown, activity history, theme control and room filtering work locally in the browser. For real appliances and sensors, connect the interface to an ESP32/Arduino backend or IoT platform.
